# 字体、文本尺寸与本地化

用于文字溢出、缺字、多语言或字体资源任务；本地化只在用户要求的语言和范围内进行。

- 保留工程已有字体方案：系统字体、TTF/OTF、位图字体、RichText 或业务本地化组件。先查真实字体资产和绑定，不为消除告警替换整个字体体系。新建 UI 缺少指定字体时按 UI 规则处理，不能据此改掉已有控件字体。
- 同时核对字号、行高、对齐、换行、UITransform 尺寸、缓存和 Overflow。CLAMP 会裁切，SHRINK 改变可读字号且动态文本可能有 CPU 成本，RESIZE_HEIGHT 会接管高度；按工程需求选择，不对所有 Label 套用同一策略。
- 用实际代表性字符串检查中文、标点、数字、图标、换行、长译文及动态拼接文本。成功赋值不代表字形覆盖或可读性；不能测量覆盖时标为未知。
- 分别检查位图字体图集、字符缓存容量、fallback 和持久化绑定。针对目标语言与尺寸截图，检查缺字、裁切、换行和布局增长。
- 本地化任务先查现有语言 ID、映射、文本 key、已写入 Label、运行时格式化和回退规则；保留已有服务，不默认引入新本地化包。
- 回读保存的字体、文本 key 和代表性运行结果。分别报告已覆盖、缺失和未验证的字符串；仅查编辑态 Label 不能证明运行时文本完整。
- 原生平台的字体性能和输入法行为需要相应设备证据。
