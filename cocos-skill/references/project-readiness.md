# 工程导入、预览与保存证据

合并自 Funplay MCP Workflow 的就绪规则。只在修改资源/脚本、启动预览、输入测试或核验保存结果时读取。

## 资源和脚本

- 先解析确切 AssetDB UUID 或 `db://` URL，只刷新实际修改的源资源；找不到时报告错误，不猜扩展名或替换为另一个资源。
- 导入是异步过程。已暴露 `check_asset_ready` 时，按精确对象检查稳定的 UUID/URL；该工具属于 `full`，不能为了调用它擅自改变用户工具配置。不可用时查询实际资源状态并说明证据较窄。
- UUID 稳定不证明导入队列清空、TypeScript 编译通过或预览加载了新脚本。脚本修改后结合诊断、Creator 导入/编译日志及实际运行验证；独立 no-emit 检查与引擎编译是不同结果。
- 零等待查询只是一条观察记录。busy、missing、importing、timeout、unknown 和接口不可用都不能视为成功。在有界期限内等候或报告未解决状态，不重放修改请求来获取更好看的结果。
- 引擎与组件 API 以实际编辑器、预览和工程代码为准，不仅凭 `package.json` 推断。

## 预览和真实输入

- 先核对预览模式。`get_runtime_state` 及暂停/恢复控制的是编辑器 Game View；`execute_javascript` 的 `scene` 是编辑器场景，真实 Web 游戏数据使用 `runtime`。Chrome 诊断按 [运行时排障](../modules/analyze-runtime-performance.md) 使用 DevTools。
- MCP 监听、窗口打开、场景有画面、截图非空、业务正确是不同证据。Scene 截图用于编辑态构图，游戏预览或实际 GameCanvas 用于运行结果；不能互相替代。
- 在 Electron 目标执行鼠标点击/拖拽时，使用该次截图返回的 `captureId` 和 `coordinateSpace: "image-pixels"`，坐标来自那张原始 PNG。缩放参考图、其他窗口或其他分辨率的坐标不能直接套用。
- resize、zoom、reload、切场景或截图过期后重新截图。校准只映射坐标，不识别按钮，也不证明遮挡、裁剪或业务结果。
- 直接触发 Button 回调只测试处理器，不证明点击命中、焦点或实际交互。输入投递状态未知时先回读，不自动重发。只恢复本任务拥有的临时状态，保留用户期间产生的变化。

## 保存和引用

- 场景、Prefab 和 `.meta` 优先通过编辑器接口修改。原生消息成功不代表已保存或 UUID 关联完整。
- 保留现有 Prefab 的节点/组件身份、嵌套关系、覆盖和动画路径。原路径上的新 Prefab 即使 UUID 相同，内部对象 ID 变化仍可能断开引用；先查依赖和入向使用，再做最小修改。
- 保存后重新查询确切对象与持久化引用，需要时重新打开检查；编辑器与磁盘不一致时先排查上下文、实例/资源和导入状态，不盲改序列化文本。
- 未完成的保存、导入、编译、预览和设备检查分别报告。
