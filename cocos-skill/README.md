# cocos-skill

面向 Cocos Creator 3.8.5 及以上的 3.8.x 工程的辅助诊断技能。运行方式见 [SKILL.md](SKILL.md)，安装方式见[仓库 README](../README.md#安装)。

- 离线检查场景和 Prefab 的对象表及 `.meta`。
- 生成素材图册，逐像素比较参考图和实际截图。
- 通过 Chrome DevTools 分析 Web 预览的网络、CPU 和内存。

开发者在仓库根目录运行 `npm --prefix cocos-skill run check` 和 `npm --prefix cocos-skill test`。历史来源见 [NOTICE.md](NOTICE.md)。
