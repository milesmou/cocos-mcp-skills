# 任务验收与离线结构检查

按改动选择检查范围，综合保存、引用、编译、结构、交互与视觉证据判断任务是否完成。底层验证、截图和预览使用 MCP 的实际工具；此模块不重新实现在线验证接口。

## 选择检查

| 改动 | 需要的证据 |
| --- | --- |
| 场景、Prefab、组件或资源引用 | 保存后重新查询编辑对象、资源依赖和 Prefab 关联；根据范围运行 MCP 的场景或引用验证 |
| TypeScript 脚本或事件回调 | 脚本诊断、注册类名、事件目标和方法，以及代表性交互或业务状态检查 |
| UI 结构与美术替换 | 节点、布局、控制器作用域、状态组、点击区域和嵌套实例与蓝图或基线一致 |
| 动态 UI、动画、业务逻辑 | 在真实游戏预览中固定数据和状态，检查操作结果、日志及画面；编辑态场景不代表运行状态 |
| 静态视觉 | 服务提供的真实 Prefab PNG 或同内容状态的游戏截图，与参考图按记录的映射比较 |
| 批量迁移或疑似序列化损坏 | 额外执行下方只读离线检查，检查磁盘对象表和元数据一致性 |

MCP 的 `validate_scene`、引用验证和脚本诊断各自覆盖不同范围，按实际返回结果判断，不能将其中一项通过描述为全部验收完成。桥接的 `validateUI` 只证明其检查范围内的结构约束，不验证视觉位置或业务正确性。

修改前记录相关基线，修改后重新检查同一范围。发现新错误时定位到具体对象和本轮修改；未解释的引用丢失、脚本错误或交互失败不能作为已完成交付。

## 视觉证据

静态 Prefab 可使用服务的 [内部渲染](../../cocos-mcp/docs/creator-bridge/prefab-preview.md)，其版本限制由服务检查。动态换图、业务数据、动画和适配需要真实运行预览；优先使用 MCP 的预览截图，普通 Web `GameCanvas` 需求可使用服务的 [运行时截图](../../cocos-mcp/docs/creator-bridge/runtime-screenshot.md)。

原始参考图、设计分辨率、图像映射、内容状态与真实截图来源必须可追踪。图片比较方法按 [UI 视觉规则](../references/assemble-cocos-ui/visual-fidelity.md) 执行；只有同尺寸、同状态且像素实际一致时才能报告完全一致。缺素材或字体差异按已验证范围说明，不能生成近似图当作真实渲染。

## 补充离线检查

保留的 `validate-project.mjs` 检查当前 MCP 未完整覆盖的磁盘不变量：非空对象表、越界 `__id__`、孤立或缺失 `.meta`、重复 UUID 和 JSON 格式错误。它只读磁盘，不包含编辑器未保存修改，也不证明脚本编译、资源导入或游戏运行正常。

```powershell
node "<技能根目录>/scripts/validate-project.mjs" --project "<工程目录>"
node "<技能根目录>/scripts/validate-project.mjs" --project "<工程目录>" --json
```

未在 `assets/` 声明的资源 UUID 仅作警告，因为它可能来自内部或挂载数据库；需要确认时由 MCP 查询资源来源，不能一律当作坏引用。

命令默认只输出到终端。需要保留报告时使用目标工程 `temp/cocos-skill/<任务>/`，本仓库验证产物使用 `.work/`。工具没有在线环境时仍可交付离线诊断，但需明确在线部分未验证，不强制启动编辑器。
