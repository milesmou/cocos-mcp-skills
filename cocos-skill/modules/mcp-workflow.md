# MCP 协作流程

本模块负责把任务拆成可验证的工程步骤。工具清单、参数、Editor 消息示例与桥接辅助能力安装由 MCP 文档维护，不在技能中复制。

## 确定编辑范围

先获得用户指定的目标工程绝对路径，调用 Codex 侧工具 `connect_cocos_project`，使用 `projectPath` 参数。默认一并安装唯一插件 `cocos-mcp-bridge` 与预览模板，包含 MCP、认证辅助方法和运行时中继。旧两插件需显式 `migrateLegacy: true`，安装器备份并迁移后返回重启提示。安装逻辑由 MCP 执行，不从技能复制插件文件。

- `restart_required`：插件已安装但当前不可用于编辑。明确告诉用户“工程桥接已安装，请保存工作并完全退出、重新打开该工程的 Cocos Creator”。若扩展未启用，提醒在扩展管理器中启用。等待用户完成，不自动重启编辑器；之后再次调用连接工具。
- `editor_unavailable`：插件已存在但编辑器尚未就绪。请用户打开正确工程，必要时重启并确认插件启用，再重新连接。
- `ready` 且 `connected: true`：核对工程路径、版本和当前编辑对象，再继续任务。
- 冲突、错误版本或工程身份不符：按工具返回的原因处理，不覆盖已有插件或猜测端口。缺少路径时仅询问目标工程路径。

连接后记录已有 dirty 状态、Prefab 实例边界、引用与需要恢复的上下文；不要为了获取截图而打开另一个工程或覆盖未保存编辑。

需求涉及 UI 时，先读取 [UI 工作流](assemble-cocos-ui.md) 形成结构、资源和交互契约。只需查询或单个底层操作时，直接使用 MCP；不强行执行完整 UI 流程。已授权制作或修复的任务，完成规格后继续实际编辑与验收。

## 组织执行

修改前查询 Prefab 所有权、依赖和反向使用；保留现有节点/组件身份、嵌套 Prefab、属性覆盖和动画路径，不用同路径重建替代局部编辑。资产复制必须取得新 UUID，不复制 `.meta`。对象缺失或接口不支持时报告具体原因，不猜替代路径、创建替身或反复执行自修复。

根据客户端当前暴露的 schema 选择工具，按“读取事实 → 小批量修改 → 回读结果 → 保存 → 验收”组织依赖步骤。UUID 和注册类名来自实际查询，不靠名称猜测；多步失败时记录已完成部分，先检查现场再决定是否重试。

`get_cocos_connection` 可重新检查当前工程状态；切换工程时必须重新调用连接工具。工具未暴露或连接不可用时明确缺少的能力，不退回独立文件脚本去修改正在运行的工程。连接断开后的修改可能已在编辑器执行，先回读现场，不自动重放写入调用。

读取正在运行的游戏数据时，用 `execute_javascript` 的 `context: "runtime"`；`scene` 是编辑器场景进程。先确认普通 Web 预览已连接，多实例从连接状态中选择实际 `instanceId`。安装或修改模板后刷新原预览，运行时查询不另开预览。参数、返回值与超时限制统一见 [运行时数据查询](../../cocos-mcp/docs/creator-bridge/runtime-javascript.md)。

## 文档入口

资源/脚本变更、预览启动、真实输入及保存核验时读取 [工程就绪与证据](../references/project-readiness.md)。保持 JavaScript 安全检查；参数用独立 `args` 传入，返回目标 UUID、操作前后值与部分失败状态。TypeScript 诊断、Creator 编译和预览加载分别检查。

Chrome 控制台、网络、时间线和堆分析使用 `cocos_devtools`，按 [运行时排障与性能分析](analyze-runtime-performance.md) 组织复现、采样和对比。先取得实际 `pageId`，保持同一会话完成采样，不以连接成功代替优化验收。

- 服务随附的 [工具手册](../../cocos-mcp/docs/TOOLS.md)：底层能力与 profile；实际参数以当前连接的 schema 为准。
- [编辑器执行说明](../../cocos-mcp/docs/EDITOR_WORKFLOW.md)：`execute_javascript` 的上下文和 Editor 消息调用。
- [桥接辅助能力](../../cocos-mcp/docs/creator-bridge/README.md)：原场景辅助方法、内部 Prefab PNG 和 Web 预览中继。

这些路径相对本仓库布局。技能通过安装器链接到 Codex；服务文档也可从连接结果的 `documentationRoot` 定位。无法取得文档时使用运行时 schema，不猜测路径或 API。

## 结束任务

按 [验收流程](validate-cocos-content.md) 选择与改动相关的检查，区分编辑态、磁盘保存状态与运行游戏。向用户交付修改对象、实际验证证据和未完成项，不能以工具调用受理或场景编辑成功代替运行验收。
